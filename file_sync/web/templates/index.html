File Sync API's

Token Generation

API Endpoint to generate token:
{{HOST_URL}}/api/v1/users/generate_token
Payload:
{ "username": "", "password": "" }

CSRF Token

API Endpoint to get CSRF token:
{{HOST_URL}}/api/v1/csrf-token
Auth: Bearer Token: {{access_token}}

File Operations

Upload Files

{{HOST_URL}}/api/v1/uploads
Multipart Form Data:
key: file value: (select file)
Headers: X-CSRF-Token: {{csrf_token}}
Auth: Bearer Token: {{access_token}}

Download Files

{{HOST_URL}}/api/v1/download?file=filename.png
Auth: Bearer Token: {{access_token}}

Stream Files

{{HOST_URL}}/api/v1/data?file=filename.png
Auth: Bearer Token: {{access_token}}

List All Files

{{HOST_URL}}/api/v1/files
Auth: Bearer Token: {{access_token}}

Delete Files

{{HOST_URL}}/api/v1/delete?file=filename.json
Headers: X-CSRF-Token: {{csrf_token}}
Auth: Bearer Token: {{access_token}}
